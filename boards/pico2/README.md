# Raspberry Pi Pico 2 Board Package

- **MCU**: RP2350A (Dual ARM Cortex-M33 / Hazard3 RISC-V @ 150MHz)
- **Package**: QFN-60 (30 GPIOs available)
- **Flash**: 4MB QSPI Flash
- **SRAM**: 520KB SRAM
- **Power**: Standard 5V VBUS (Micro-USB) with 3.3V internal buck-boost regulator

## WebUI Assets
- `board.json`: Declarative pinout, capabilities, and zones
- `logo.svg`: Raspberry Pi Pico 2 branding
- `favicon.svg`: Pico 2 web favicon
- `pinout.svg`: Interactive 40-pin DIP vector diagram with DOM element IDs matching `pin-gpX`
