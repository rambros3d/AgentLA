# Feature Parity: C Firmware (AgentLA) vs Rust Firmware (AgentLA-rust)

Generated by research comparison of:
- C reference: `/home/sun/Filelink/Firmwares/AgentLA` (firmware C, openspec/specs, README)
- Rust port: `/home/sun/Filelink/Firmwares/AgentLA-rust` (firmware-rs crate, openspec changes/archive/specs)

LOC snapshot: C `firmware/src` ≈ 32,095 LOC (incl. littlefs core ~7k); Rust `firmware-rs/src` ≈ 10,294 LOC.

Status legend: **Completed** = implemented and exercised; **Partial** = core exists, gaps remain; **Scaffolded** = stub/module only; **Not Ported** = absent or evidence only in C.

## Per-domain summary

- Core system: **Partial** — storage/profile/pin-ownership strong; app routing and OTA gaps.
- Programmer: **Partial** — CMSIS-DAP + SWD + RVSWD core solid; target portfolio and flash-algorithm runner still narrow.
- Analyzer: **Partial** — capture/compression + many decoders; DMA streaming, scope, VCD missing.
- Adapters: **Partial** — I3C/UART/USB tiny I²C; SPI master and mature I²C master missing.
- Peripherals: **Partial/Scaffolded** — PWM/servo strong; scope/signal generator partial.
- Network: **Completed (core)** — NCM/DHCP/DNS/HTTP/MCP; SSE missing.
- Web platform: **Partial** — REST/desktop emerging; web_desktop module scaffolded.
- Storage: **Completed** — LittleFS + profiles + apps mostly ported.

## Next milestones (high-value)

1. **Full target & flashing parity**: expand `programmer/target/*` and `algo` blobs to cover the C target portfolio (PY32, nRF52840, STM32 families, RP2040/RP2350, CH5xx) with read/erase/program/verify and RDP operations.
2. **Logic analyzer fidelity**: implement PIO/DMA streaming into the larger capture bank, multi-condition triggers, scope mode, and VCD/Sigrok export.
3. **Adapter completion**: port SPI bus master and a full interactive I²C master (scan/read/write) plus mature CAN frame tooling.
4. **Web desktop assets**: move beyond scaffold in `web_desktop.rs` to a complete embedded UI asset bundle, SSE streams, and profile UI parity.

## Top 3 unimplemented high-value features

1. **Full target MCU portfolio + autonomous flash programming** (C `firmware/src/programmer/target.c`, `algo_runner.c`) — Rust only supports 3 hard-coded probe profiles and basic flash read.
2. **SPI bus master bridge** (C `firmware/src/adapter/adapter.c`) — Rust exposes only `CAP_SPI` pin capability; no SPI driver/REST bridge.
3. **VCD/Sigrok export & analog scope** (C logic analyzer scope/export) — Rust analyzer has `Mode::Scope` constant only; no analog capture or VCD emitter.
