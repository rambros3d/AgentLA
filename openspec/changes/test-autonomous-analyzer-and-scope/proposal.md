## Why

The AgentLA board provides extensive Logic Analyzer (10-channel up to 100MHz), Oscilloscope (ADC channels on GPIO 26-28), Protocol Decoders (UART, I2C, SPI), and Bus Adapter features. However, end-to-end autonomous validation requires a reliable test signal source. By connecting a second Raspberry Pi Pico 2 via USB as an autonomous signal generator and loopback partner, we can systematically verify edge captures, ADC scope metrics, and protocol decoding without external instrumentation or manual jumper re-wiring.

## What Changes

- Add a dedicated multi-signal generator and echo responder firmware for the target Pico 2 (`test-firmware/target-pico2-generator`).
- Implement automated Python test suites that drive AgentLA's Logic Analyzer, Scope, and Adapter commands against the target.
- Verify Oscilloscope ADC channels (`ADCSCOPE pin=26`, `27`, `28`) for voltage range, frequency, and waveform metrics.
- Verify Logic Analyzer (`CAPTURE`) edge detection, pulse width timing, and sampling integrity across flexible pool pins `GPIO 20`, `21`, `22`.
- Verify UART and I2C protocol decoders with live on-wire traffic generated by the target board.
- Verify Adapter loopback communication between AgentLA and the target.

## Capabilities

### New Capabilities
- `autonomous-hardware-verification`: Automated test framework running against a live RP2350 target signal generator to validate ADC Scope, Logic Analyzer digital edge timings, and protocol decoders.

### Modified Capabilities
- `analog-oscilloscope`: Add live hardware verification requirements for multi-channel ADC sampling accuracy, frequency calculation, and voltage ranges on RP2350.

## Impact

- `test/test_autonomous_hardware_verification.py`: End-to-end integration test suite.
- `test-firmware/target-pico2-generator/`: Target firmware generating known PWM, clock edges, UART packets, and I2C response frames.
- Documentation and test results in `docs/` and test logs.
