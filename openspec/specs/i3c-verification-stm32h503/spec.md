## Requirements
### Requirement: Automated STM32H503 I3C Target Firmware Provisioning
The test suite SHALL use AgentLA's built-in SWD programmer engine to flash a dedicated I3C Target test firmware onto an STM32H503 microcontroller.

#### Scenario: Successful target flash and reset
- **WHEN** the verification runner initiates the test against an attached STM32H503 target
- **THEN** AgentLA connects via SWD, validates `PART_ID = 0x474` (STM32H503), erases flash sector 0, writes the compiled STM32H503 I3C target test binary, resets the target, and verifies firmware boot.

### Requirement: End-to-End Dynamic Address Assignment (ENTDAA) Verification
The test suite SHALL verify that AgentLA successfully executes ENTDAA against the STM32H503 target's hardware I3C peripheral.

#### Scenario: Verification of STM32H503 PID and address assignment
- **WHEN** AgentLA executes `I3C_ENTDAA` against the STM32H503 in target mode
- **THEN** the STM32H503 responds with its valid STMicroelectronics Provisional ID, BCR, and DCR, accepts dynamic address 0x08, and AgentLA reports matching target descriptors.

### Requirement: End-to-End SDR Register Read/Write Verification
The test suite SHALL execute bi-directional register read and write operations between AgentLA (Controller) and the STM32H503 (Target) at various clock frequencies up to 12.5 MHz.

#### Scenario: Write followed by read-back loopback check
- **WHEN** AgentLA writes an arbitrary 32-byte payload to the STM32H503 test register memory and subsequently reads back the same memory
- **THEN** the read payload bitwise matches the written payload without parity errors, NACKs, or framing violations.

### Requirement: Target-Initiated In-Band Interrupt (IBI) Verification
The test suite SHALL verify that AgentLA detects, arbitrates, and services an In-Band Interrupt generated by the STM32H503 target.

#### Scenario: STM32H503 triggers hardware IBI
- **WHEN** the test fixture commands the STM32H503 to trigger an I3C IBI with a known Mandatory Data Byte (MDB = 0xA5)
- **THEN** AgentLA's `I3C_POLL` command detects the interrupt request, provides the target address, acknowledges the MDB, and returns `OK I3C IBI addr=0x08 mdb=0xA5`.
