All-In-One Bench Architecture

Engineered for hardware reverse engineering, automated regression tests, and interactive target bring-up.

100 MS/s Logic Analyzer

10-Channel PIO0 capture engine with multi-touch pinch-to-zoom, nanosecond resolution, and real-time SPI, I2C, and UART protocol decoding.

Multi-Arch Flasher

High-speed target flashing supporting standard ARM SWD, RISC-V RV-SWD, and WCH QingKe 1-wire SDI with hardware memory verify.

Hardware Debugger

Halt, step, run, and live RAM memory hex inspection for Cortex-M0+/M33 and RISC-V RV32EC cores directly inside your browser.

Dynamic Pin Ownership

Strict driver/observer arbitration: GPIO 0–9 fixed programmer block; GPIO 10–29 flexible dynamic pool with conflict protection.

Bus Masters (I2C / SPI / I3C)

Hardware bus controllers with automated peripheral scanning, register read/write sequences, and live protocol transaction logs.

Agent & MCP Integration

Native Model Context Protocol (MCP) server endpoints allowing AI coding agents to control instruments and analyze signals autonomously.

PWM Signal Generator

Slice-accurate hardware PWM and clock synthesis from 1 Hz to 50 MHz across GPIO 10–29 with duty cycle and pulse controls.

4-Channel Analog Scope

Real-time SAR ADC oscilloscope on GPIO 26–29 (ADC 0–3) with 0–3.3V tracking and dual-personality digital return on close.

Connecting to Hardware

AgentLA presents an RNDIS USB Ethernet interface providing an embedded web server and JSON-RPC API.

1

Plug in USB-C

Connect your AgentLA RP2350 probe to your workstation. The device enumerates as a USB Composite Device with CDC-ACM serial and RNDIS Ethernet.

2

Auto-IP Network

AgentLA hosts an embedded DHCP server allocating your host machine an address on the 192.168.7.0/24 subnet.

3

Open WebUI

Navigate to http://agentla.local or http://10.10.10.10 in any modern browser for full zero-install control.
